# FaceTrack - Location and Facial Recognition Based Attendance System



## 📌 Overview
FaceTrack is a smart attendance system leveraging **facial recognition** and **geolocation tracking** to streamline attendance processes in educational institutions, workplaces, and events. Built with **Next.js, Tailwind CSS, MongoDB, and APIs**, FaceTrack eliminates manual sign-ins, reduces administrative overhead, and enhances accuracy.

### 🚀 How I Got This Idea
During my college placement drives, manual attendance was taken by signing a paper, which was inefficient for over **400 students**. This led me to develop FaceTrack, a scalable solution with **automated checks, real-time tracking, data visualizations**, and an **exportable attendance report**.

## ✨ Features
- 🔐 **Facial Recognition** - Secure, fast, and accurate using **Face-api.js**.
- 📍 **Geolocation Tracking** - Ensures attendance authenticity.
- 📊 **Admin Dashboard** - Visual insights and real-time data.
- 📥 **Excel Export** - Download attendance reports instantly.
- 📈 **Branch-wise Analytics** - Understand attendance trends.
- 🎨 **Modern UI** - Built with **Tailwind CSS** for a sleek design.

## 🚀 Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/yourusername/facetrack.git
cd facetrack
```

### 2️⃣ Install dependencies
```bash
npm install
```

### 3️⃣ Configure environment variables
```bash
cp .env.example .env
# Edit .env file with your credentials
```

### 4️⃣ Run the project
```bash
npm run dev
```
